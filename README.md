# MetrOpros – система опросов-голосований

MetrOpros позволяет создавать опросы и встраивать их на любые сайты.  
Пользователь управляет своими опросами, просматривает статистику, а посетители сайтов могут голосовать без регистрации.

## Основные возможности

- Регистрация и авторизация пользователей (по логину или email).
- Создание опроса:
  - название,
  - от 1 до 10 вариантов ответа,
  - цветовая тема (4 встроенные темы),
  - список доверенных доменов (или разрешить все сайты).
- Встраивание опроса на сайт через `<iframe>`.
- Голосование с защитой от повторных голосов с одного устройства (через сессию).
- Статистика по каждому опросу:
  - горизонтальная гистограмма в процентах,
  - количество голосов по каждому варианту,
  - общее количество голосов.
- Автоматическое хеширование паролей.

## Технологии

- **Backend**: PHP (без фреймворков, процедурный + ООП).
- **Frontend**: HTML, CSS, минимальный JS (только для отображения ошибок, гистограмма на CSS).
- **База данных**: MySQL.
- **Паттерны**: MVC, Singleton (доступ к БД), Factory, Strategy (авторизация).
- **Инструменты**: Visual Studio Code, XAMPP (Apache + MySQL), GIMP (макеты и иконки).

## Установка и запуск

### Требования
- Веб-сервер с поддержкой PHP (рекомендуется Apache + XAMPP).
- MySQL.
- PHP 7.4 или выше.

### Пошаговая инструкция

1. **Склонируйте репозиторий**  
   ```bash
   git clone https://github.com/ваш-username/MetrOpros.git
   ```
2. **Импортируйте базу данных**
  Создайте базу данных metropros (или другое имя) и импортируйте файл database.sql (в репозитории должен быть предоставлен – при необходимости создайте вручную по описанию ниже).

3. **Настройте подключение к БД**
  Отредактируйте файл MVC/Model/DatabaseInteractor.php (указать хостинг, логин, пароль, имя БД).
По умолчанию (для локального XAMPP) можно использовать:
  ```php
  $this->connection = new mysqli('localhost', 'root', '', 'metropros');
  ```
4. **Настройте веб-сервер**
  Поместите проект в корневую папку (например, htdocs/MetrOpros).
Убедитесь, что модуль mod_rewrite включён (необязательно, но рекомендуется для чистых URL).
5. **Запустите**
  Откройте в браузере http://localhost/MetrOpros/index.php.

Структура базы данных (основные таблицы)
user_login_information – пользователи (id, login, password_hash, email).

polls – опросы (id, user_id, poll_name, color_theme, trusted_domains, ...).

polls_variants – варианты ответов (id, poll_id, variant_text, votes).

**Защита и ограничения**
* Пароли хранятся в хешированном виде (password_hash()).

* При голосовании проверяется сессия ($_SESSION['voted_'.poll_id]), что предотвращает повторные голоса с одного браузера.

* При создании опроса проверяется уникальность названия для данного пользователя.

* Доверенные домены можно задать вручную (через запятую) или разрешить все.
